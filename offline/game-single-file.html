電腦

方向鍵 ←→ 轉彎・↑ 油門・↓ 煞車・Shift 甩尾・Ctrl 或 Z 用氮氣・H 按喇叭・R 回到賽道・Esc 暫停

手機

自動油門，左下角搖桿（手指按下就出現）轉彎，「煞」減速，「甩尾」按住甩尾，「氮氣」噴射，📣 喇叭，右上 ⏸ 暫停

甩尾與氮氣

過彎時按住甩尾，氮氣條會慢慢集滿，滿一格就能噴射，最多存兩格。連續幾個彎道都甩尾，會有「連彎獎勵」，額外加氮氣。

護欄與草地

彎道外側有護欄，撞到會減速但不會翻車；開到草地速度會減半。髮夾彎外側沒有護欄，衝出去如果跑到逆向，按 R 或等幾秒會自動回到賽道。

道具賽

撿路上的黃色問號箱得到道具：🩴拖鞋（飛向前方對手）、🟥檳榔汁（丟在後面讓人打滑）、🧋珍珠奶茶（3秒加速＋無敵）、🛡️護盾（擋一次攻擊）、🚀加速。按 X 鍵或點左側道具格使用。

聯賽

連續三場（白天、黃昏、夜間），依名次拿積分 10/6/3/1，跑完依總積分領獎金。
